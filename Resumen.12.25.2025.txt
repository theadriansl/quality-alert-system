5. SISTEMA DE SEGUIMIENTO DUAL (PLANEADO vs REAL)
================================================================================
REQUERIMIENTO DEL USUARIO:
"me gustaría más bien que el usuario metiera lo que avanzó en cierto día,
como dos líneas una de planeado y otra de real"

IMPLEMENTACIÓN:
✅ Dos tipos de progreso:
  - PLANEADO: Calculado automáticamente según fechas (% de tiempo transcurrido)
  - REAL: Ingresado manualmente por el usuario (0-100%)

EN VISTA LISTA:
- Dos barras horizontales lado a lado
- Barra gris = Progreso Planeado
- Barra de color (según prioridad) = Progreso Real
- Campo de entrada numérica para actualizar el progreso real

EN VISTA GANTT:
- Barra gris clara de fondo = Duración planeada completa
- Barra de color superpuesta = Progreso real
- Label muestra: "Real% / Planeado%"

FUNCIONES CLAVE:
```javascript
// Calcula progreso planeado basado en fechas
const calculatePlannedProgress = (startDate, endDate) => {
  // Si hoy está entre inicio y fin: calcula % de días transcurridos
  // Si hoy < inicio: 0%
  // Si hoy > fin: 100%
}

// Usuario actualiza progreso real manualmente
handleUpdateDefinitiveAction(id, { actualProgress: newValue });
```
