1. RESUMEN DE LA FUNCIONALIDAD
================================================================================

OBJETIVO:
---------
Permitir al usuario ingresar las cantidades de partes afectadas en diferentes
ubicaciones y calcular automáticamente el impacto total de costos.

UBICACIONES SOPORTADAS:
-----------------------
🏭 Almacén (Warehouse)
⚙️ En Proceso (In Process)
🚚 En Tránsito (In Transit)
👤 Con Cliente (With Customer)

CÁLCULOS AUTOMÁTICOS:
---------------------
✅ Total de piezas afectadas = Suma de todas las ubicaciones
✅ Impacto total de costo = Total afectado × Costo unitario
✅ Totales generales por ubicación
✅ Costo total acumulado de todas las partes

CÓDIGO CLAVE:
-------------
```javascript
const handleQuantityChange = (partIndex, field, value) => {
  const updatedParts = [...parts];
  const part = { ...updatedParts[partIndex] };

  // Convertir a número entero
  const qty = parseInt(value) || 0;
  part[field] = qty;

  // Calcular total afectado
  part.totalAffectedQty =
    (part.qtyWarehouse || 0) +
    (part.qtyInProcess || 0) +
    (part.qtyInTransit || 0) +
    (part.qtyWithCustomer || 0);

  // Calcular impacto de costo
  part.totalCostImpact = part.totalAffectedQty * (part.unitCost || 0);

  updatedParts[partIndex] = part;
  onPartsUpdate(updatedParts);
};
```

const qtyWarehouse = parseInt(part.qtyWarehouse) || 0;
const qtyInProcess = parseInt(part.qtyInProcess) || 0;
const qtyInTransit = parseInt(part.qtyInTransit) || 0;

6. CÓMO USAR LA FUNCIONALIDAD
================================================================================

PASO A PASO:
------------

1. CREAR NUEVO REPORTE 8D
   - Navegar a "Nuevo 8D"
   - Completar información básica

2. SELECCIONAR CLIENTE Y PROYECTO
   - Elegir cliente de la lista
   - Elegir proyecto asociado
   - Sistema carga partes disponibles

3. SELECCIONAR PARTES AFECTADAS
   - Marcar checkboxes de las partes afectadas
   - Puede seleccionar múltiples partes
   - Resumen aparece automáticamente

4. INGRESAR INVENTARIO
   📊 Tabla de Inventario aparece automáticamente

   Para cada parte:
   a) Almacén: Ingresar cantidad en almacén
   b) En Proceso: Ingresar cantidad en producción
   c) En Tránsito: Ingresar cantidad en envío
   d) Con Cliente: Ingresar cantidad en sitio del cliente

   Los campos "Total Afectado" e "Impacto Total" se calculan automáticamente

5. VERIFICAR TOTALES
   - Revisar fila de totales al final de la tabla
   - Revisar panel de "Impacto Total Estimado"
   - Costo total se calcula sumando todas las partes

6. GUARDAR REPORTE
   - Click en "Guardar" o "Continuar"
   - Datos de inventario se guardan en base de datos
   - Pueden editarse después si es necesario
