---

## ✅ LO QUE YA ESTÁ IMPLEMENTADO

### 1. BACKEND - Endpoints de Quotes
**Archivo**: `backend/endpoints/quotesEndpoints.js`

Endpoints disponibles:
- `GET /quotes` - Listar cotizaciones (con filtro opcional por jobId)
- `GET /quotes/:id` - Obtener cotización específica
- `POST /quotes` - Crear nueva cotización
- `PUT /quotes/:id` - Actualizar cotización existente
- `DELETE /quotes/:id` - Eliminar cotización
- `POST /quotes/:id/export` - Marcar cotización como exportada

### 2. FRONTEND - Servicio de Quotes
**Archivo**: `frontend/src/services/quoteService.js`

Métodos implementados:
- `getAll(jobId)` - Obtener todas las cotizaciones
- `getById(id)` - Obtener cotización por ID
- `create(quoteData)` - Crear cotización
- `update(id, quoteData)` - Actualizar cotización
- `delete(id)` - Eliminar cotización
- `markAsExported(id, exportType)` - Marcar como exportada

### 3. FRONTEND - Crear Cotización
**Archivo**: `frontend/src/pages/CreateQuote.js`

**Características del formulario**:

#### Sección 1: Client / Bill-To Information (Auto-rellenada desde Job)
- Company
- Contact Name
- Billing Address
- City, State, Zip Code
- Phone
- Email

#### Sección 2: Service Location (Editable)
- Company
- Contact Name
- Address
- City, State, Zip Code
- Phone
- Email

#### Sección 3: Project Information
- Project Description (auto-rellenada desde Job)
- Part Descriptions
- Agreed Upon Services
- Estimated Hours

#### Sección 4: Service Rates (USD per hour)
Tabla de tarifas con dos roles:
1. **Working Supervisor**
2. **Rework Team Member / Inspector**

Tipos de tarifa para cada rol:
- Shift 1
- Shift 2/3
- Overtime
- Saturday
- Sunday
- Holiday

**Valores por defecto**:
- Working Supervisor: $29.00 (regular), $43.50 (overtime/weekend), $53.50 (holiday)
- Inspector: $26.00 (regular), $39.00 (overtime/weekend), $52.00 (holiday)

#### Sección 5: Additional Terms
- Minimum Hours per Team Member (default: 4)
- Overtime Threshold (default: 40 hours)
- Material Markup (default: 10%)

#### Sección 6: Purchase Order Information (Opcional)
- Purchase Order Number
- Purchase Order Amount

**Funcionalidad**:
- Auto-rellena datos del cliente y job al cargar
- Permite editar todas las tarifas y términos
- Guarda como "Draft" al crear
- Navega de vuelta a JobDetail sección Documents después de guardar

### 4. FRONTEND - Visualización en JobDetail
**Archivo**: `frontend/src/pages/JobDetail.js` (líneas 1589-1764)

**Sección "Documents"** (case 'documents'):
- Título: "Quotes & Documents"
- Botón "New Quote" (navega a `/jobs/:jobId/quotes/new`)
- Lista de cotizaciones con:
  - Quote Number
  - Fecha y estado (Draft/Sent/Accepted/Rejected)

- Click en cotización navega a `/jobs/:jobId/quotes/:quoteId` (⚠️ RUTA NO IMPLEMENTADA)
- Estados con colores:
  - Accepted: Verde
  - Sent: Azul
  - Rejected: Rojo
  - Draft: Amarillo

  exportedAt: string | null,
  exportType: string | null

## 🔄 FLUJO DE USUARIO ACTUAL

1. **Ver Job** → JobDetail → Click en tab "Documents"
2. **Crear Cotización** → Click "New Quote" → Formulario CreateQuote
3. **Llenar Formulario** → Datos auto-rellenados + editar tarifas
4. **Guardar** → Se guarda como "Draft" → Regresa a Documents tab
5. **Ver Lista** → Cotizaciones aparecen en la lista con estado/fecha
6. **⚠️ Click en Cotización** → FALLA - No existe QuoteDetail.js
