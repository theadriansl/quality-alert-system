ADD COLUMN IF NOT EXISTS d7_completed BOOLEAN DEFAULT false;

ALTER TABLE eightd_reports

## 3. Problemas Encontrados y Soluciones

### **Problema 1: Validación de Permisos de Subida de Fotos**
**Descripción:** Las fotos estaban bloqueadas por la validación `isD6FormBlocked`

**Feedback del Usuario:** "og siparece bloqueado"

**Análisis:** El usuario explicó que sería bloqueado si D6 ya está aprobado

**Solución:**
```javascript
// Photos upload is less restricted - only block if approved
const isD6PhotoUploadBlocked = data?.d6Status === 'approved';
```

**Respuesta del Usuario:** "esta bien, digo podemos trabajar en un problema nuevo luego para hacer debugging"

### **Problema 2: Layout de Fotos No Visible en Dos Secciones**
**Descripción:** El usuario no veía el layout en dos columnas para la subida de fotos

**Feedback del Usuario:** "no veo el layout en dos secciones"

- Implementé CSS Grid con `gridTemplateColumns: '1fr 1fr'`
