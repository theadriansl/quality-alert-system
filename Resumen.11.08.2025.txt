1. TASK FORCE TEAM (TFT) - CONCEPTO
   --------------------------------
   Propuesta del usuario:
   "que en usuarios pudieramos hacer un TFT que sea el equipo encargado de
   atender cualquier 8d, tal vez al ponerlo en una columna de TFT y con
   checkbox por usuario y asi se da por default cuando se abra un 8D"

   Ventajas sobre otras alternativas:
   - Más simple que asignar equipos por cliente (clientes grandes como Marelli)
   - Más flexible que asignar equipos por proyecto
   - Equipo core siempre disponible para nuevos 8D
   - Permite modificación posterior del equipo asignado

   C. Función handleTFTToggle
      ------------------------
      Ubicación: frontend/src/pages/UserManagement.js (líneas 315-346)

      Código completo:
      ```javascript
      const handleTFTToggle = async (userId, currentStatus) => {
        try {
          const newStatus = !currentStatus;
          console.log(`🔄 Toggling TFT membership for user ${userId} to ${newStatus}`);

          const response = await fetch(
            `http://localhost:5000/users/${userId}/tft-membership`,
            {
              method: 'PUT',
              headers: {
                'Content-Type': 'application/json'
              },
              body: JSON.stringify({ isTFTMember: newStatus })
            }
          );

          const data = await response.json();

          if (data.success) {
            // Update local state
            setUsers(prev => prev.map(user =>
              user.id === userId
                ? { ...user, isTFTMember: newStatus }
                : user
            ));

            alert(data.message);
          } else {
            alert('Error al actualizar TFT: ' + data.message);
          }
        } catch (error) {
          console.error('❌ Error toggling TFT membership:', error);
          alert('Error al actualizar membresía TFT');
        }
      };
      ```

      Flujo de la función:
      1. Calcula nuevo estado (toggle del actual)
      2. Hace PUT request al backend
      3. Si success: actualiza estado local de React
      4. Muestra mensaje de confirmación del backend
      5. En caso de error: muestra mensaje de error

   -----------------------

   Sistema: Muestra tabla con columna TFT
