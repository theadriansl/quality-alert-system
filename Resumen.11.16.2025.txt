1. ARCHIVOS ADJUNTOS SE BORRABAN AL GUARDAR REPORTE EXISTENTE
--------------------------------------------------------------
PROBLEMA: Al guardar un reporte existente, las fotos y documentos desaparecían
CAUSA RAÍZ: En 8DWorkflow.js línea 234, SIEMPRE se llamaba createEightdReport()
            incluso para reportes existentes, creando uno NUEVO sin adjuntos

SOLUCIÓN (8DWorkflow.js:234-250):
```javascript
const isExistingReport = updatedData.id && !isNaN(updatedData.id);

if (isExistingReport) {
  // ACTUALIZAR reporte existente (no crear uno nuevo)
  console.log('📝 Updating existing report ID:', updatedData.id);
  reportId = updatedData.id;
  await eightDService.updateEightdReport(reportId, reportData);
  savedReport = { id: reportId };
} else {
  // CREAR nuevo reporte
  console.log('🆕 Creating new report...');
  savedReport = await eightDService.createEightdReport(reportData);
  reportId = savedReport?.id;
}
```

TAMBIÉN: Solo subir archivos nuevos (instanceof File), no re-subir URLs existentes:
```javascript
if (updatedData.photoNoGood && updatedData.photoNoGood instanceof File) {
  // Upload solo si es File, no URL string
}
```

CAUSA RAÍZ: eightDService.js devolvía array vacío [] en vez de ['', '', '', '', '']

SOLUCIÓN (eightDService.js:373-396):
```javascript
// Ensure nonDetectionReasons has exactly 5 elements (for 5 Why's)
const rawNonDetectionReasons = report.d3NonDetectionReasons || [];
const normalizedNonDetectionReasons = Array.isArray(rawNonDetectionReasons) && rawNonDetectionReasons.length > 0
  ? [...rawNonDetectionReasons, '', '', '', '', ''].slice(0, 5)  // Ensure 5 elements
  : ['', '', '', '', ''];

// Ensure detectionPoints has proper structure
const rawDetectionPoints = report.d3DetectionPoints || {};
const normalizedDetectionPoints = {
  duringProcess: rawDetectionPoints.duringProcess || { yes: false, no: false },
  afterManufacture: rawDetectionPoints.afterManufacture || { yes: false, no: false },
  priorDespatch: rawDetectionPoints.priorDespatch || { yes: false, no: false }
};

const d3Data = {  // Siempre crear objeto, nunca null
  detectionPoints: normalizedDetectionPoints,
  nonDetectionReasons: normalizedNonDetectionReasons,
  // ... otros campos
```

TRANSFORMACIÓN CAMELCASE - RECORDATORIO CRÍTICO
================================================================================

⚠️ transformToCamelCase() es RECURSIVO:

PostgreSQL Column          → JavaScript Property
------------------------   ----------------------
issue_assigned_to          → issueAssignedTo
d3_detection_points        → d3DetectionPoints
d3_non_detection_reasons   → d3NonDetectionReasons
escalation_path            → escalationPath (JSONB)

DENTRO del JSONB:
{ issue_users: [1,2,3] }   → { issueUsers: [1,2,3] }

¡Los contenidos JSONB también se transforman!
