## ESTRATEGIAS DE NEGOCIACIÓN

### OPCIÓN A: CONSULTOR ESPECIALIZADO (RECOMENDADA)
**Propuesta:**
```
"Prefiero estructurar esto como consultoría especializada.
Tengo un sistema APQP propietario ya desarrollado que
necesito proteger como IP separada."
```

**Términos sugeridos:**
- **Rate:** $150-200/hora (equivale a $24K-32K/mes full-time)
- **Compromiso:** 20-30 horas/semana inicialmente
- **Duración:** 6-12 meses con renovación
- **IP:** Claramente excluida del contrato
- **Deliverables:** Implementación específica para Eaton

**Ventajas:**
✅ Conservas tu IP completamente
✅ Mayor ingreso por hora
✅ Flexibilidad para otros clientes
✅ Relación comercial, no empleado
✅ Puedes escalar tu propio negocio paralelamente

### OPCIÓN B: EMPLEADO CON PROTECCIÓN IP
**Si insisten en empleado, negociar:**

**Cláusulas críticas:**
```
1. "Exclusión de IP preexistente"
   - Sistema APQP desarrollado antes del contrato
   - Lista específica de funcionalidades excluidas

2. "Declaración de invenciones previas"
   - Documento legal de IP anterior
   - Protección explícita de código existente

3. "Limitación de asignación de invenciones"
   - Solo aplica a trabajo específico para Eaton
   - No incluye mejoras a sistema preexistente

4. "Término específico del contrato"
   - 12 meses máximo inicialmente
   - Cláusula de salida sin penalización
```
