────────────────────────────────────────────────────────────────────────────
3. D4: IMPLEMENTACIÓN EXTRAORDINARIA - ANÁLISIS 4M + 5 WHYS AUTOMÁTICO
────────────────────────────────────────────────────────────────────────────

⭐ IMPLEMENTACIÓN MÁS SIGNIFICATIVA DEL DÍA ⭐

CONCEPTO:
Sistema avanzado de análisis de causa raíz que combina:
- Evaluación sistemática por categorías (6M)
- Análisis profundo de causa raíz (5 Whys)
- Sincronización automática entre ambas herramientas

ARQUITECTURA IMPLEMENTADA:

📊 SECCIÓN 1: EVALUACIÓN 6M (Tabla de 10 columnas)
┌─────────────────────────────────────────────────────────────────────┐
│ Categoría | Punto Control | Norma | Doc | Real | STD | CAL | Com |│
│           |               |       |     |      |     |     |     |│
│  [6M ▼]  |  [texto]      |[texto]|[doc]|[real]|[▼] |[▼] |[txt]|│
└─────────────────────────────────────────────────────────────────────┘

Categorías (6M):
- Mano de obra
- Máquina
- Material
- Método
- Medición
- Medio Ambiente

Juicios:
- OK: fondo verde ✅
- NG: fondo rojo 🔴 (trigger automático)

🔍 SECCIÓN 2: ANÁLISIS 5 WHYS (Tabla de 7 columnas - Auto-generada)
┌────────────────────────────────────────────────────────────────────┐
│ Factor NG | 1.Why? | 2.Why? | 3.Why? | 4.Why? | 5.Why? | Causa  │
│           |        |        |        |        |        | Raíz   │
└────────────────────────────────────────────────────────────────────┘

Características:
- Solo visible cuando hay NG
- Fondo rojo claro para destacar problemas
- Columna "Causa Raíz" con fondo amarillo
- Sincronización automática

✅ SECCIÓN 3: RESUMEN DE CAUSA RAÍZ (Fondo verde)
- Causa Raíz Principal * (textarea)
- Marcar D4 como Completada (checkbox)

LÓGICA AUTOMÁTICA (LO EXTRAORDINARIO):
╔══════════════════════════════════════════════════════════════════╗
║  🤖 SINCRONIZACIÓN INTELIGENTE                                   ║
╠══════════════════════════════════════════════════════════════════╣
║  ✅ OK → NG:  Crea automáticamente fila en tabla 5 Whys         ║
║  ✅ NG → OK:  Elimina automáticamente de tabla 5 Whys           ║
║  ✅ Cambio de nombre: Actualiza automáticamente Factor NG       ║
║  ✅ Eliminar evaluación: Elimina análisis 5 Whys asociado      ║
╚══════════════════════════════════════════════════════════════════╝

Frontend:

   - Estado: d4_4mEvaluation[], d4_5whysAnalysis[]

Handlers Implementados:

FLUJO DE TRABAJO:
1️⃣ Usuario evalúa puntos de control en tabla 6M
2️⃣ Al marcar NG → Sistema crea automáticamente análisis 5 Whys
3️⃣ Usuario completa los 5 porqués para cada NG
4️⃣ Usuario identifica causa raíz en tabla 5 Whys
5️⃣ Usuario escribe resumen consolidado en sección final
6️⃣ Usuario marca D4 como completada ✅
