================================================================================

PROBLEMA RAÍZ IDENTIFICADO:
---------------------------
El reporte en la base de datos (ID: 4, report_id: 8D-2025-0316) tenía el estado:
  d1_d2_d3_approval_status = 'pending_approval_1'

Las pestañas D4 y D5 solo se habilitan cuando:
  isD123Approved = workflowData?.d1D2D3ApprovalStatus === 'approved'

Por eso D4 y D5 estaban BLOQUEADAS (no era un problema de código).

SOLUCIÓN APLICADA:
------------------
Se ejecutó un script para actualizar la base de datos:

UPDATE eightd_reports
SET d1_d2_d3_approval_status = 'approved',
    current_approval_step = 3,
    approval_1_status = 'approved',
    approval_2_status = 'approved',
    approval_3_status = 'approved'
WHERE id = 4;

Resultado: D4 y D5 ahora están DESBLOQUEADAS
