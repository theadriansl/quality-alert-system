NOTAS IMPORTANTES

ESTRUCTURA DE CÓDIGO:
1. React functional components con hooks
2. Traducción i18n con hook t()
3. Estilos inline (no CSS modules)
4. Grid CSS para layouts de 2 columnas
5. Arrays mapeados con key={index} para items dinámicos

PATRÓN DE SECCIONES:
Cada sección de contenido sigue este patrón:
```javascript
<div style={styles.section}>
  <h3>{emoji} {t('sectionName')}</h3>
  <p>{t('sectionDesc')}</p>
  {formData.sectionArray.map((item, index) => (
    <div key={index} style={styles.arrayItem}>
      <div style={{ marginBottom: '12px' }}>
        // ... inputs y textareas ...
      </div>
      // ... evidence section si existe ...
      <div style={{ display: 'flex', gap: '8px' }}>
        <button onClick={handleSave}>💾</button>
        <button onClick={() => removeItem(index)}>Eliminar</button>
      </div>
    </div>
  ))}
  <button onClick={addItem}>+ Agregar</button>
</div>
```

EVIDENCIAS:
- Cada item puede tener array de evidencias: { name, url }
- Upload se maneja con input[type=file] oculto
- Estado uploadingEvidence previene uploads simultáneos
- handleEvidenceUpload recibe (type, index, event)
- removeEvidence recibe (type, itemIndex, evidenceIndex)

VALIDACIONES:
- isFormBlocked: true cuando usuario no es responsable
- isSaving: true durante guardado para prevenir doble-click
- handleSave valida isFormBlocked antes de guardar
- No hay validaciones de campos requeridos en draft save

TRADUCCIONES:
