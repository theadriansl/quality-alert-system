DIFERENCIADOR CLAVE DEL PRODUCTO
================================================================================

🎯 MOTOR DE APROBACIONES MULTINIVEL CONFIGURABLE

Este es el diferenciador letal vs competencia (TrackWise, Intelex, ETQ):
- Competencia: Workflows rígidos, adaptarse a su proceso
- Nosotros: Drag-and-drop configuración de stages y aprobadores
- Resultado: Mismo motor sirve para 8D, ECR, Auditorías, Work Orders, CAPA, etc.

Por qué importa:
- Cada empresa tiene flujos únicos (Tier 1 vs Tier 2 vs OEM)
- Cambios organizacionales requieren flexibilidad
- Multi-proceso reduce costos (1 sistema = múltiples usos)

SERVICIO DE APROBACIONES (Backend)
--------------------------------------------------------------------------------
Archivo: backend/services/approvalService.js

Funcionalidades Clave:
1. getWorkflowStages(workflowType)
   - Retorna stages configurables por tipo de documento
   - Tipos: '8D', 'ECR', 'Audit', 'WorkOrder', 'CAPA', 'QuickAlert'

2. requestApproval(documentId, stage, userId)
   - Crea solicitud de aprobación
   - Envía notificación al aprobador
   - Establece SLA de aprobación

3. approve(approvalId, approverId, comments)
   - Registra aprobación
   - Avanza al siguiente stage si aplica
   - Notifica a siguiente aprobador

4. reject(approvalId, approverId, reason)
   - Registra rechazo
   - Notifica a creador original
   - Devuelve documento a stage anterior

5. escalate(approvalId, escalationReason)
   - Escala a superior si SLA vencido
   - Notifica a ambos aprobadores

6. getApprovalHistory(documentId, documentType)
   - Retorna historial completo de aprobaciones
   - Para auditoría y trazabilidad

Configuración Flexible:
const workflows = {
  '8D': [
    { stage: 'D0-D3', approver_role: 'quality_engineer', required: true, sla_hours: 24 },
    { stage: 'D4-D5', approver_role: 'quality_manager', required: true, sla_hours: 48 },
    { stage: 'D6-D7', approver_role: 'plant_manager', required: false, sla_hours: 72 },
    { stage: 'D8', approver_role: 'customer', required: true, sla_hours: 120 }
  ],
  'ECR': [...],
  'Audit': [...],
  'WorkOrder': [...],
  'QuickAlert': [
    { stage: 'review', approver_role: 'supervisor', required: true, sla_hours: 8 }
  ]
};

- escalation_reason
