3. FUNCIÓN FETCH TFT MEMBERS
   --------------------------
   Ubicación: frontend/src/pages/Create8D.js (líneas 314-329)

   Funcionalidad:
   - Llama a endpoint GET /users/tft-members
   - Retorna array de usuarios con isTFTMember: true
   - Maneja errores de red
   - Console logging para debugging

   Código:
   ```javascript
   const fetchTFTMembers = async () => {
     try {
       const response = await fetch('http://localhost:5000/users/tft-members');
       if (response.ok) {
         const data = await response.json();
         if (data.success) {
           console.log('✅ TFT Members loaded:', data.tftMembers);
           return data.tftMembers;
         }
       }
     } catch (error) {
       console.error('❌ Error loading TFT members:', error);
       return [];
     }
   };
   ```

4. MANEJADOR DEL CHECKBOX TFT
   ---------------------------
   Ubicación: frontend/src/pages/Create8D.js (líneas 331-354)

   Funcionalidad:
   a) Al ACTIVAR (check):
      - Llama a fetchTFTMembers()
      - Asigna todos los miembros TFT al equipo
      - Marca todos como selected: true
      - Muestra alert con cantidad de miembros asignados
      - Si no hay miembros TFT: alerta y desmarca checkbox

   b) Al DESACTIVAR (uncheck):
      - Muestra confirmación: "¿Desea remover los miembros del TFT?"
      - Si confirma: limpia array de teamMembers
      - Si cancela: mantiene checkbox marcado

   Código:
   ```javascript
   const handleTFTToggle = async (checked) => {
     setUseTFT(checked);

     if (checked) {
       const members = await fetchTFTMembers();
       if (members && members.length > 0) {
         setTeamMembers(members.map(m => ({ ...m, selected: true })));
         alert(`✅ Se asignaron ${members.length} miembros del TFT`);
       } else {
         alert('⚠️ No hay miembros en el Task Force Team');
         setUseTFT(false);
       }
     } else {
       if (window.confirm('¿Desea remover los miembros del TFT?')) {
         setTeamMembers([]);
       } else {
         setUseTFT(true);
       }
     }
   };
   ```

5. FUNCIONES DE GESTIÓN DE EQUIPO
   --------------------------------
   Ubicación: frontend/src/pages/Create8D.js (líneas 356-377)

   A. toggleTeamMember(userId)
      - Activa/desactiva un miembro individual
      - Actualiza propiedad 'selected'
      - Mantiene miembro en la lista

   B. addTeamMember(user)
      - Agrega miembro adicional (no TFT)
      - Valida que no exista duplicado
      - Lo marca como selected: true

   C. removeTeamMember(userId)
      - Remueve miembro completamente de la lista
      - Filtra el array teamMembers

   Código:
   ```javascript
   const toggleTeamMember = (userId) => {
     setTeamMembers(prev =>
       prev.map(member =>
         member.id === userId
           ? { ...member, selected: !member.selected }
           : member
       )
     );
   };

   const addTeamMember = (user) => {
     if (!teamMembers.find(m => m.id === user.id)) {
       setTeamMembers(prev => [...prev, { ...user, selected: true }]);
     }
   };

   const removeTeamMember = (userId) => {
     setTeamMembers(prev => prev.filter(member => member.id !== userId));
   };
   ```
